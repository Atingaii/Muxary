# Muxary 0.1.0 — source development milestone

## English

Muxary is an AGPL-3.0-only derivative of SeemSeam/claude_codex_bridge, based on
upstream 8.7.22 (`df98e61e91b4be57873029b01667135e6265f371`). This version starts
an independent fork version line; it does not describe an already-published npm
package, GitHub binary release, or signed mobile application.

- `muxary` opens the local loopback Web workbench; `muxary tui` delegates to the
  existing CCB terminal interface. The `ccb` entry point and internal protocols
  remain compatible.
- The Web adapter reuses CCB project/agent/job and native terminal ownership;
  it does not introduce another scheduler or completion authority.
- CodeBuddy support uses exact native session logs and generation-bound
  SessionStart bindings, including native clear/compact session changes.
- Package and updater identity point only to `Atingaii/Muxary`. If no fork
  release is available, use the documented source installation, not an upstream
  binary fallback.

Source development status is separate from release acceptance. Browser,
cross-provider, installer/rollback, and reproducible artifact gates must pass
before claiming a published release. Existing upstream history remains credited
in the repository; mobile artifacts are not claimed for this milestone.

## 中文

Muxary 基于 SeemSeam/claude_codex_bridge 8.7.22 的上述固定提交，是保留
AGPL-3.0-only 许可的衍生项目。0.1.0 是独立版本线的源码开发里程碑，
不表示 npm、GitHub 二进制或签名移动端已发布。

- `muxary` 默认开启仅本机 loopback Web；`muxary tui` 复用原 CCB TUI。
  旧 `ccb` 入口及内部协议保持兼容。
- Web 复用 CCB 的项目、Agent、Job 与原生终端所有权，不增设调度或完成权威。
- CodeBuddy 用精确原生日志和启动代次绑定跟踪会话，包括 clear/compact 换号。
- 包和更新器仅指向 `Atingaii/Muxary`；fork 无可用 release 时走源码安装，
  不回落安装上游二进制。

源码开发状态不等于发布验收通过。真实浏览器、跨 provider、安装回滚和可复现
构建门槛须通过后才能宣称正式发布；本里程碑不宣称提供移动端产物。
