## 已明确的用户目标

1. 基于现有 CCB 二次开发 Muxary，新增 CodeBuddy CLI 平台支持。
2. 不是只给配置页换皮：Web 要能承载日常 Agent 使用和桌面式工作流程。
3. 改进布局、视觉层级、交互及失败状态；从 <https://21st.dev/> 选择现有组件或原型再适配，不从零重写通用 UI。
4. 通过 CodeBuddy 的 DeepSeek v4.1 Flash 和 Opus 5.5 与主审共同评审方案，记录实际调用，不虚构讨论。
5. 命令与产品品牌对应 Muxary；主命令默认 Web，`muxary tui` 与兼容 `ccb` 保留原 TUI 行为和脚本协议。
6. 完成开发和全面测试；以 grill 逐轮澄清并保留 ADR/SPEC。不将研究、测试收集、Mock 验证或截图冒充完整真实联通。

## 已接受验收维度与证据入口

- **运行真实性**：任务提交进入现有 dispatcher；发送回执不等于完成；界面终态与 ccbd 权威结果一致。
- **状态持续性**：刷新、切换 Agent、任务 watch 查询/终端 WS 断开与恢复不制造重复任务或错误终态；取消与完成竞态明确。
- **能力诚实性**：工具审批、历史会话、模型切换等由实际能力决定，不把 OMP 专用能力推广到所有 Provider。
- **桌面使用体验**：高频操作不进入设置；键盘导航、中文输入、焦点、可折叠面板（初版折叠；后续终端增加 Resizable）、空态/加载/失败态可验证。
- **隔离与身份**：同源认证、过期/撤销令牌、项目/Agent 越界请求、CLI 共存和更新源有独立反例测试。
- **组件复用**：记录具体 21st 来源、版本或 hash、许可证、保留声明与修改边界；不因选择 UI 组件重写调度器或引入外部 Agent 云。
- **测试证据**：区分 Python 回归、前端单测/构建、浏览器端到端、真实 CLI/模型联通和平台未测边界。全面测试不表示未执行平台也通过。

上述是验收要求而非统一通过证书；已执行结果与未覆盖边界见[验收报告](../research/muxary-validation.md)。原生审批在终端完成；本机 BFF 不新增公网监听，既有 CCB 远程能力不因此获得新的验收背书。

## 已实现的信息结构

选取 21st AgentChat **Basic**，复用固定版本的 InputBar、UserMessage、Markdown、Suggestions 及其必要依赖。项目/Agent 导航、可折叠真实任务和 Git diff、原生终端是 CCB 产品适配，不声称来自上游完整页面模板。“工作台任务”与“原生会话”是独立来源视图，避免重复渲染或凭文本猜测统一时间线。Composer 明示目标 Agent，点任务卡只切换目标，不自动发送；快捷模板只填入草稿。

右栏运行指示来自真实 jobs，无模拟进度。设置复用原配置页。diff 仅含 tracked、unstaged 变更；历史仅限现有 queue/view 能定位的条目，不是永久完整档案。


CodeBuddy 启动预检读取真实启用的设置来源；目前仅支持严格 JSON，JSONC 明确拒绝且不修改。预检不保证启动后同用户动态修改配置的持续隔离。原生账号验证限 Linux 2.183.0，插件/MCP 或其他平台不作全兼容声明。
